                            **Image Gallery Web App (CodeAlpha Internship Task)**

A responsive image gallery web application built with HTML, CSS, and JavaScript.

### Features:
- **Interactive Lightbox / Fullscreen View:** Click any image to view it in full screen with smooth navigation.
- **Slideshow Mode:** Automated slideshow option to play through images seamlessly with play/stop controls.
- **Next & Previous Navigation:** Easy-to-use arrows and interactive bottom thumbnail drawer to browse through images.
- **Favorites System:** Mark and save your favorite images.
- **Recycle Bin / Trash Management:** Move images to the trash and manage deleted files.
- **Category Filtering & Search Bar:** Filter images instantly by categories (Nature, Animals, Plants, Sports, Food, etc.) or search by name.
- **Light & Dark Theme Toggle:** Switch seamlessly between dark mode and professional light mode.
- **Fully Responsive:** Optimized UI layout that looks and works perfectly on both laptops/PCs and mobile phones.

### How to Run:
Simply download or clone the repository and open `ImageGallery.html` in any web browser.
