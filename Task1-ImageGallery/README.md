**Task 1: Image Gallery Web Application (CodeAlpha Internship Task)**
A responsive and interactive Image Gallery web application built with HTML5, CSS3, and JavaScript, featuring a dynamic lightbox viewer and real-time category search filtering.

---

**Features:**
- **Interactive Lightbox:** Click on any image to view it in a full-screen modal overlay with smooth transitions.
- **Search Filtering:** Real-time search bar to instantly filter images based on keywords or tags.
- **Category Tabs:** Filter images by categories (e.g., Nature, Architecture, Technology, etc.).
- **Fully Responsive:** Designed with modern CSS Flexbox and Grid to look stunning on mobile phones, tablets, and desktop screens.

**How to Run:**
1. Download or clone the repository to your local machine.
2. Open the `Task1-ImageGallery` folder.
3. Open `ImageGallery.html` in any web browser to view and interact with the application.
