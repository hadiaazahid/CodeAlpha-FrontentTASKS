**Melody Music Player**

A sleek, responsive, and feature-rich web-based music player built with vanilla JavaScript, HTML5, and CSS3. Designed with a modern UI inspired by popular streaming platforms, it allows users to enjoy a seamless music playback experience directly in their browser.

Features

- **Core Playback Controls:** Play, pause, skip forward, skip backward, and seek through tracks using an interactive progress bar.
- **Playlist Management:** Browse through a curated list of tracks with dynamic search and filtering options (All Songs vs. Liked Songs).
- **Shuffle & Repeat:** Randomize your playback order or loop your favorite tracks seamlessly.
- **Volume & Mute Control:** Adjust audio volume levels or mute instantly with dynamic volume icons.
- **Favorites System:** Save your favorite tracks using local storage so your preferences persist across sessions.
- **Keyboard Shortcuts:** Control playback quickly using intuitive keyboard shortcuts (Spacebar for play/pause, Arrow keys for navigation and volume).
- **Responsive Design:** Fully responsive layout that looks great across desktop screens.

**How to Run:**
1. Download or clone the repository to your local machine.
2. Open the `Task4-MusicPlayer` folder.
3. Open `MusicPlayer.html` in any web browser to view and interact with the application.
