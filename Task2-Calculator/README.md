Smart & Simple Web Calculator (CodeAlpha Internship Task)

A modern, feature-rich web calculator and a dynamic layout built with HTML, CSS, and JavaScript.

### Features:
- **Responsive Design:** Optimized layout tailored for both desktop viewports and mobile devices with clean, centered container alignment.
- **Theme Switcher:** Seamless toggle between Deep Ocean Dark Mode and professional Light Mode.
- **Fullscreen Mode:** Option to expand the workspace for an immersive computing experience.
- **Advanced Operations:** Standard arithmetic operations alongside square roots, percentages, and clean input formatting.
- **Clean UI Interface:** Styled with elegant serif typography and well-spaced grid keypad alignments to prevent overflow.

### How to Run:
Simply download or clone the repository and open your project file (or run via a local server like `python -m http.server 8000`) in any web browser.
