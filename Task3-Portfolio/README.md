**Task 3: Professional Portfolio (CodeAlpha Internship Task)**

A responsive professional portfolio web application built with HTML5, CSS3, and JavaScript, featuring custom service descriptions, interactive UI components, and a specialized "stereo" (two-card) mobile layout.


**Features:**
- **Smooth scroll:** Specially designed scroll buttons, animations and hover etc
- **Professional Services Section:** Detailed custom service descriptions showcasing web development and front-end design expertise.
- **Interactive UI Components:** Smooth navigation, dynamic content rendering, and responsive styling.
- **Fully Responsive:** Optimized layout that looks and works seamlessly on both laptops/PCs and mobile phones.

**How to Run:**
1. Simply download or clone the repository.
2. Open `Portfolio.html` in any web browser to view the portfolio.
